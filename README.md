# Real World City — 365-Day Living City (v3.1)

**🌐 公開URL: https://sinjorjob.github.io/real-world-city/**

---

**あなたの仕事の1年が、成長し続けるリアルな都市になる。**

状況・悩みを入力すると、疑似AIエンジンが解析してあなた専用の都市と**1年分の動的シナリオ**を生成。
四季が巡る明るくリアルな3D都市が自律的に育ち、数日ごとに画面下へ現れる**意思決定ドック**の選択が
都市の未来を分岐させる、シムシティ型シミュレーションゲーム。

`検討/real_world_city_claude_context.md` の仕様書に基づく実装(v3.1)。
**完全オフライン動作**(three.js / OrbitControls 埋め込み済み、CDN不要)。

---

## 使い方

```
https://sinjorjob.github.io/real-world-city/ をブラウザで開くだけ（ビルド不要・ネット不要）
※ ?demo=1 で自動デモ（サンプル入力→自動意思決定）
```

1. 状況を入力 → **GENERATE CITY** → 朝の明るい都市が立ち上がる
2. 都市は**DAY 1〜365**を自律的に進む(1日=20秒、▶▶▶で20倍速)
   - 毎日1〜14区画が着工(クレーン→竣工)、増床、空き地が尽きたら**建て替えで高層化**
   - 昼夜サイクル + **四季**(春=桜混じり/夏=深緑/秋=紅葉/冬=枯れ色)で街路樹約700本が変化
3. **意思決定ドック**: 固定UIはなし。出来事が起きた時だけ画面下にドックが出現し(時間停止)、
   毎回異なる選択肢を提示。SIM HUDの「次の出来事」で次の発生日が分かる
4. DAY 2/26/52は**成長戦略イベント**(Quick Win / Workflow / Agent から選択・後日追加可)、
   90日ごとに**四半期レビュー**(拡大/効率/人材)、スコア到達で**観覧車→ツインタワー→スカイタワー**建設
5. DAY 365で**年次総括** → 2年目へ継続可能
6. 介入: 空き地クリック=即開発 / 建物クリック=意味・ゾーン情報

## CITY ANALYSIS は LIVE 連動

右パネルの5ゲージは**毎日リアルタイムに変動**する(パネル見出しに LIVE 表示):
- 業務成果接続度 ← スコア・選択した戦略数・都市の発展度に毎日引き寄せられる
- 業務整理度 ← 渋滞が残っていると下がり、解消すると伸びる
- 自動化準備度 ← 沼の埋立・工場稼働で日々上昇
- 精神負荷/AI圧力 ← 渋滞・沼・放置で増え、戦略と成果で減る + 日々のゆらぎ
- 変化したゲージは**数値が脈打ち、▲▼の増減矢印**(良い変化=緑/悪い変化=赤)を表示。意思決定・デイリーイベントの増減も即反映

## 動的シナリオエンジン

- **意思決定テンプレート22種+**: 入力テーマ(会議/Excel/資料/焦り/単発利用/属人化/学習過多/成果要求…)の
  ヒット数で出現確率が変わり、都市状態(沼が残っているか/渋滞中か)・季節・選択済みルート・**過去の選択フラグ**で条件分岐
- **チェーンイベント**: 「マクロ職人の引き留め失敗」→後日「💥月次集計が壊れた」など、選択が未来のイベントを生む
- 各選択肢は メトリクス増減 / スコア / 成長ブースト(ゾーン指定可) / 渋滞係数 / フラグ を持ち、効果はタグで事前表示
- 60日クールダウン+条件×パラメータ×状態の組合せで、プレイごとに異なるシナリオが生成される

## 実装のポイント

- **1ファイル完結・完全オフライン**: Three.js r128とOrbitControls(共にMIT)をハッシュ検証済みバイトで埋め込み。CDN障害・社内ネットワーク制限の影響を受けない
- 建物約540棟を**15アーキタイプのInstancedMesh**+屋根+室外機+樹木×2+車両パーツ×2+街灯+パッドで描画
- シミュレーションは仮想時間(意思決定中は停止)。成長率 = 基本1 + 戦略数 + 選択による期限付きブースト
- 意思決定は条件(入力テーマ×都市状態×季節×フラグ)×重み抽選×チェーンで実質無限に分岐
- `analyze()` 1関数差し替えでClaude API化可能。意思決定テンプレートも同じJSON形状でAI生成に置換できる設計
